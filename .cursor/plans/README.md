# Saved Agent Plans

Future implementation plans should be saved in this directory before significant code work. Plans should cite the required docs and make acceptance criteria testable.

## Template

```markdown
# Plan: Feature Name

## Goal

What this implementation changes and why.

## Required Reading

- `AGENTS.md`
- `docs/axioms/...`
- `docs/specs/...`
- `docs/decisions/...`

## Files to Modify

- `path/to/file`

## Acceptance Criteria

- Observable, testable outcomes.

## Forbidden

- Shortcuts or side effects this plan must not introduce.

## Tests

- Unit tests.
- Integration tests.
- Contract or fixture tests.
```
